# Change a form's public link

Open **Forms Studio → Builder → Settings → General** for the form. In **Public link**, change **Link name**, then select **Publish form / Update form**. Autosaving the draft alone does not change the public URL.

For example, changing `tic-2025-registration` to `tic-2027-registration` creates `https://uticx.com/form/tic-2027-registration` after saving. The title and intake are separate settings; changing the link does not change the form's records or intake.

Use 1–100 lowercase letters, numbers, and single hyphens. A link cannot begin or end with a hyphen, include spaces or slashes, or belong to another form. Previous names remain reserved for the same form.

Previously shared links, Google Form webhook URLs, and existing secure application email links keep resolving to the original form. Closed forms and candidate authentication checks still apply. **More → Copy published link**, **Open published form**, and the webhook script use the published name. **Preview** displays the current draft without changing the published URL.

If another administrator changes the form, reload and review it before saving again. A duplicated form receives its own link and does not inherit the original form's link history.
