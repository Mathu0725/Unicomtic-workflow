# Edit each form's popup and messages

Open **Forms Studio → Builder → 5. Messages & popup** for the form.

Use **Enable popup** and **Enable bottom messages** to control visibility separately for this form. Both start enabled on existing and new forms. Turning either switch off preserves all saved wording; turn it back on to restore the same messages. Select **Save Form** to publish the switches.

Turning the popup off hides the automatic dialog and the reopen button. Turning bottom messages off hides the English and Tamil submit instructions and automatic draft saving notice below the button. The submit button, automatic draft saving, restored draft controls, validation and error messages keep working.

Edit the English and Tamil submit instructions, automatic draft saving notice, restored draft notice, popup headings and additional instructions. You can also change the submit, view-instructions and continue button labels. Keep the submit instructions consistent with the submit button text.

Use **Preview popup** to inspect the instructions dialog. The below-button preview uses the same message component as the public form. Select **Save Form** to publish the messages for this form.

Messages are plain text. Separate additional popup bullet points with a blank line. Optional text can be cleared to hide it. Editing the wording does not disable automatic draft saving or alter submission processing.

**View instructions button text** is optional. Leave it empty to hide the reopen button. When **Enable popup** is on, the popup still opens automatically and **Preview popup** remains available in Builder. When the switch is off, the popup and its preview are hidden.

**Load default messages** prepares the original wording in the editor and keeps your visibility switches; save to apply it. Existing forms retain the original defaults until edited. Duplicating a form copies its saved messages and visibility switches, and later edits remain independent.

If another administrator changes the form, reload and review the current version before saving. Public visitors receive only resolved display messages; email automation and integration credentials remain private.
